# Personal Investment Portfolio Tracker

An Excel-based investment portfolio management and financial analysis tool designed to track transactions, monitor holdings, calculate portfolio performance, and visualize investment data through a dashboard.

## Project Overview

This is a self-initiated finance and FinTech portfolio project built using Microsoft Excel.

The tracker organizes investment transactions into a structured workflow and converts them into holdings, portfolio metrics, performance analysis, and visual insights.

The project was created to strengthen practical skills in financial analysis, Excel, portfolio tracking, and data visualization.

## Objectives

- Track investment transactions in a structured format
- Calculate holdings and total invested capital
- Include brokerage costs in investment cost calculations
- Monitor current portfolio value
- Calculate unrealized profit/loss and portfolio returns
- Analyze portfolio allocation across holdings
- Present key portfolio metrics through a dashboard

## Project Workflow

Transactions → Holdings → Analysis → Dashboard

### 1. Transactions

Records individual investment transactions including:

- Date
- Stock name
- Stock symbol
- Transaction type
- Quantity
- Price per share
- Brokerage
- Total transaction amount

### 2. Holdings

Converts transaction data into a current portfolio view containing:

- Quantity held
- Average buy price
- Brokerage
- Total invested amount
- Current market price
- Current portfolio value
- Unrealized profit/loss
- Return percentage
- Portfolio weight

### 3. Analysis

Summarizes important portfolio-level metrics such as:

- Total invested capital
- Current portfolio value
- Total unrealized profit/loss
- Overall portfolio return
- Number of holdings
- Largest holding
- Best-performing holding
- Lowest-performing holding

### 4. Dashboard

The Excel dashboard provides visual analysis through:

- Portfolio allocation chart
- Profit/loss by stock
- Invested vs. current portfolio value
- Key performance indicators

## Limitations

This project is designed for portfolio tracking and financial analysis using illustrative data.

Current limitations include:

- Market prices are entered manually
- Real-time market data is not connected
- Realized profit/loss is not fully modeled
- Taxes and other advanced trading costs are not included
- The tracker does not connect directly to a brokerage account
